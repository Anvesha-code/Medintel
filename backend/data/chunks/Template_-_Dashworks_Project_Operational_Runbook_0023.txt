Setting the Request Type by Individual User

The request type for a user can be found by searching for the user’s corp id or by finding the user object from one of the Dashworks dashboards.

The Request Type selection lives in the tab ‘Details’

Click on the tab named Details.

At the bottom of this screen you will find a drop down selector for Request Type.
