11.2.2. Setting the Forecast Date

The forecast date can be set using three different mechanisms:

Individually on each user through the Dashworks application

Bulk updating users through the Dashworks application

Bulk updating users through a CSV file import

11.2.2.1. Setting the Forecast Date by Individual User

The forecast date for a user can be found by searching for the user’s login id or by finding the user object from one of the Dashworks dashboards.
