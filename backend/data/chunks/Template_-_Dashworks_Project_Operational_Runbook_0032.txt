ulk update function in the Dashworks application.

Click on Actions -> Bulk Update

Click on Task Update

Select Users

Select the Stage called Forecasting (T-30)

Select the task called Forecast Date

Click on the check box and Set the date by using the date control

Click on Choose Users…

Either paste in the LOGIN ID of the users, or find them in the database by selecting the browse button

Click on Select Users

Click on Perform Update
