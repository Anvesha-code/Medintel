12.3. Setting the Scheduled Date

If the user or users are ready to move forward in the process, the next step is to set the schedule date.

The Scheduled Date lives in the stage Pre-Migration

You can set the scheduled date by following the same steps as outlined in the section entitled ‘Setting the Forecast Date’. Substitute Forecast Date for Scheduled Date.
