If an application needs to be onboarded (i.e. it exists in Dashworks Analysis, but not in the Dashworks Project System), it can be onboarded using the following process:

Select Onboarding -> Onboard Objects

Click on the radio button for Applications

You can either paste the application name into the box from the Analysis side of the system, or you can click on Browse to find it.

<INSERT SCREENSHOT OF ONBOARDING APPLICATIONS PAGE>

If Browse… was selected, choose the application you want to onboard from the list.
