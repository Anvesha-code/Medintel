15.1. Onboarding Applications

In order for applications to be managed, they must be onboarded into Dashworks. There are two ways an application can be onboarded:

• As part of a user or computer onboard

• As a direct application onboard

If a user is the first user of an application in the project, the application is onboarded along with the user account and a new application object is created in the project system.
